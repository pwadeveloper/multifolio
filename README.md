# Multimudia portfolio

Video editing portfolio with Selected Work, Pricing, private local work manager,
and a server-side Paystack hosted checkout.

## Local development

Requires Node.js 22+ and Python 3 for the private manager.

```sh
npm run dev                   # http://localhost:8778
python3 admin_server.py 8779   # http://localhost:8779
```

The manager uses username `admin` and the generated password in
`.work-admin-password`. That file is owner-readable only, ignored by Git, and
outside the public website. The manager listens on loopback only. Add, preview,
edit, and remove YouTube/Instagram URLs; changes persist in `mirror/works.json`.
Local gallery pages refresh that collection every 15 seconds or on window focus.
The deployed site receives a snapshot of this file: commit and push changes to
publish them. The private manager is intentionally not deployed to Vercel.

## Payments and booking

The starting package is **4 short videos + 1 long-form video**, priced at
**₦450,000 NGN or $350 USD**, as a **one-time payment**. There is no recurring
subscription or automatic monthly charge.

“Book an intro call” opens:
https://calendar.app.google/4Z1x1rKG1f6mJqTu9

“Start my retainer” opens `/checkout`. The server validates the customer details,
sets the amount itself (45,000,000 kobo or 35,000 US cents), initializes Paystack,
and sends the customer to hosted checkout. The callback verifies payment status,
reference, currency, amount, and package metadata against Paystack before showing
confirmation. Payment records remain in the Paystack dashboard. This version
does not automatically fulfil services, send onboarding email, or maintain an
orders database.

### Secret keys

**Do not put live keys in chat, Git, public JavaScript, or the private work-manager form.**

In Vercel, open the `multifolio` project → Settings → Environment Variables.
Add `PAYSTACK_SECRET_KEY` with your Paystack live secret (`sk_live_…`) for the
**Production** environment and mark it sensitive. Then redeploy the project.
For Preview testing use a separate Paystack test secret (`sk_test_…`).
A public key is not needed by this hosted checkout implementation.

Optional configuration:

| Variable | Purpose |
| --- | --- |
| `SITE_URL` | Canonical site origin, e.g. `https://multifolio.vercel.app`; Vercel supplies a fallback. |
| `PAYSTACK_USD_ENABLED` | Set to `true` only when USD collection is activated for your Paystack account. Defaults to NGN checkout only. |
| `BOOKING_URL` | Optional override of the configured Google Calendar URL used by the standalone booking page. |

With no secret configured, the payment form is disabled and visitors are directed
to book a call. Never use a `NEXT_PUBLIC_` or other public prefix for the secret.
For local API testing, copy `.env.example` to `.env.local` and add a **test** key.

Paystack settings: the callback is supplied per transaction; no webhook is
required for the current manually fulfilled workflow. Before adding automated
fulfilment, implement a signature-verified, durable, idempotent webhook handler.
[Official transaction API schema](https://github.com/PaystackOSS/openapi/blob/master/dist/paystack.yaml).

## Deploy

```sh
npm test
npm run build
vercel --prod
```

Vercel builds public files into `dist/` and deploys only `/api` payment functions.
The build uses an explicit public file list, excluding the local manager,
credentials, and removed gallery routes. Connect GitHub `pwadeveloper/multifolio`
to Vercel for deployment on pushes to `main`.

The static React/RSC shell is retained from the starting project. HTML and RSC
responses share the same Pricing content tree, generated by:

```sh
python3 scripts/build_pricing.py
```

After changing pricing content, run that script and commit both generated files.
Do not run the earlier migration scripts to make routine portfolio changes.

## Checks

```sh
npm test                      # Payment validation and verification, mocked provider
python3 scripts/test_admin.py # Isolated admin auth, CRUD, and link validation
```

No real payment is made by the test suite.
